# Hainan Travel Planning System / 海南旅游规划系统

## Overview / 概述

This is a comprehensive travel planning system for a 8-day/7-night trip to Hainan, China for 4 people.

这是一个为4人设计的海南8天7晚深度游的完整旅游规划系统。

## Files / 文件说明

- **HainanTravelPlanner.cs**: C# program that generates a complete travel plan with flights, hotels, attractions, food recommendations, and detailed itinerary
  - C# 程序，生成包含航班、酒店、景点、美食推荐和详细行程的完整旅游计划

- **海南旅游攻略.md**: Comprehensive travel guide in Markdown format (Chinese)
  - Markdown 格式的完整旅游攻略（中文）

## Trip Details / 行程详情

- **Travel Dates / 旅行日期**: November 15-22, 2025 (2025年11月15日-22日)
- **Duration / 时长**: 8 days / 7 nights (8天7晚)
- **Travelers / 人数**: 4 people (4人)
- **Budget / 预算**: ¥29,524 total / ¥7,381 per person (总计¥29,524 / 人均¥7,381)

## How to Run / 如何运行

### Prerequisites / 先决条件
- .NET SDK 6.0 or higher
- .NET SDK 6.0 或更高版本

### Running the Program / 运行程序

```bash
# Navigate to the Code directory
cd Code

# Compile the program (if using .NET Framework)
csc HainanTravelPlanner.cs

# Or use dotnet (recommended)
dotnet run HainanTravelPlanner.cs

# The program will display:
# - Flight recommendations
# - Hotel options
# - Attractions list
# - Food recommendations
# - 8-day detailed itinerary
# - Budget breakdown
# - Travel tips
```

## Tips / 小贴士

1. **Book in Advance / 提前预订**: Flights and hotels should be booked 1-2 months ahead
2. **Sun Protection / 防晒**: SPF50+ sunscreen is essential
3. **Seafood / 海鲜**: Buy at markets and use processing shops for best value
4. **Duty-Free / 免税**: Register for membership in advance, collect before departure
5. **Transportation / 交通**: Car rental or charter recommended for flexibility
